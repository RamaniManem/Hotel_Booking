# 🏨 StayEase – Hotel Booking Platform

StayEase is a responsive hotel booking website designed to provide users with a smooth and interactive room-searching and booking experience. It features elegant room cards, image galleries, guest filters, booking forms, dynamic price calculations, and confirmation dialogs.

## ✨ Features

- **Modern Homepage:** Attractive hero section with hotel branding.
- **Room Categories:** Four room types:
  - Standard Room
  - Deluxe Room
  - Executive Suite
  - Family Room
- **Room Image Galleries:** Three images displayed for each room category.
- **Room Amenities:** Displays facilities such as air conditioning, Wi-Fi, smart TV, and more.
- **Interactive Room Search:** Search using check-in date, check-out date, and guest count.
- **Guest Filtering:** Filters room options according to guest capacity.
- **Dynamic Price Calculation:** Calculates the estimated booking cost based on room price and number of nights.
- **Booking Form:** Collects guest details and stay information.
- **Form Validation:** Checks required fields, phone number, dates, and guest capacity.
- **Confirmation Modal:** Displays a summary of the booking request.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all four project files are present.
4. Open `index.html` using Live Server.
5. Explore the rooms, search for accommodation, and test the booking form.

## 📌 Project Limitations

This is a front-end demonstration project. Room availability is simulated using guest capacity. It does not connect to a real hotel database, process payments, or create actual reservations. External room images require an internet connection.
